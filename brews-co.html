Point of Sale Java AI Integration

Brew's Co.

Developed a full-stack Point of Sale (POS) system for Brew’s Co. Shop to address the challenges of manual order-taking, inventory management, and sales tracking, which were time-consuming and prone to errors. The system was built using Java, Apache NetBeans, MySQL, and a graphical user interface to automate order processing, receipt generation, real-time inventory updates, sales monitoring, and user management, while integrating an AI-powered feature that analyzes high-selling products and generates combo meal suggestions to support sales strategies and customer engagement. As a full-stack developer, I contributed to both the frontend interface and backend functionality, including database integration and core system features. The completed system streamlined daily business operations, reduced manual errors, improved transaction and inventory management, and provided organized sales and administrative monitoring.
