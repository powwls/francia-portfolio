ShopSphere

Developed a full-stack e-commerce website, ShopSphere, designed to provide users with a simple, responsive, and user-friendly platform for browsing products and managing online purchases. The website was built using React.js for the frontend, Node.js for the backend, and MySQL for database management, implementing core e-commerce features such as product browsing, category filtering, search functionality, shopping cart management, user authentication, wishlist management, checkout, and order processing. As the sole developer, I handled the complete development process, including designing the user interface, developing frontend components, implementing backend functionality, integrating the database, and developing the website's core features. The completed website provided an organized and responsive shopping experience while demonstrating my ability to independently develop and integrate a full-stack e-commerce system from frontend to backend.
